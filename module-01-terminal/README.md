# Terminal Fundamentals

A hands-on Linux exercise covering directory navigation,
file management and basic text editing.

## What I Did

- Created a lab workspace with linux, networking and backup folders
- Created, copied, moved and renamed files
- Used output redirection to record results
- Practised editing text with Vim

## Evidence

[View the command log](./command-log.txt)

The log records the final directory contents and commands used.

## What I Learned

How to navigate a filesystem, use relative and absolute paths,
and verify the results of file operations.
