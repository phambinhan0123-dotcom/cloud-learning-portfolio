# Cloud Learning Journey

This repository documents my progress towards becoming internship-ready for a Cloud Engineering role.

I am a Bachelor of Computing Science student at the University of Technology Sydney (UTS). My current cloud provider focus is Amazon Web Services (AWS).

## Career Goal

My goals are to:

- Begin applying for internship opportunities near the end of Year 1.
- Become internship-ready between the middle and the end of Year 2.
- Develop practical skills in Linux, networking, Git, AWS and cloud operations.

## Learning Progress

### Module 01 — Terminal Fundamentals

- Navigating directories with `pwd`, `ls` and `cd`
- Creating files and directories
- Copying and moving files
- Using output redirection
- Editing text files with Vim

### Module 02 — Linux and Bash

- Reading and filtering text files
- Using pipes with commands such as `grep`, `sort`, `uniq`, `cut` and `wc`
- Understanding basic file permissions
- Reading log files
- Writing a basic Bash script to analyse logs

### Module 03 — Internet, Web and HTTP

- Understanding how the Internet and the Web work
- Understanding DNS and IP addresses
- Understanding TCP and IP
- Reading HTTP requests and responses
- Understanding HTTP methods, headers and status codes
- Understanding the difference between HTTP and HTTPS
- Understanding basic TLS concepts
- Inspecting requests with browser Developer Tools and `curl`

### Module 04 - Git and GitHub

- Creating and organising a GitHub repository
- Tracking changes with meaningful commits
- Using branches to work on changes separately
- Organising learning evidence into folders
- Maintaining a project README
- Creating and merging Pull Requests

## About Me

I am a Computing Science student interested in Cloud Engineering, cloud operations, networking, monitoring and troubleshooting.
